# Buckets Arena

Site estático responsivo para o projeto Buckets Arena, inspirado na estética de games de basquete, com paleta preta, laranja e off-white.

## Conteúdo incluído
- Página inicial / hub
- Área editorial do Blog Buckets BR com links para YouTube e Instagram
- Quiz de basquete interativo com pontuação por sessão
- Glossário Basquês com busca por termo, tradução e significado
- Link externo para a Buckets Shop
- Layout responsivo para celular e desktop

## Como visualizar
Abra `index.html` no navegador. O site usa HTML, CSS e JavaScript sem framework ou etapa de build. A fonte usa Google Fonts; caso esteja sem internet, haverá fallback para fontes locais.

## Como publicar no GitHub Pages
1. Crie um repositório separado, por exemplo `buckets-arena`.
2. Envie `index.html`, `style.css`, `script.js` e este README para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, escolha `main` e `/ (root)`, e salve.
5. Aguarde o GitHub publicar o endereço do site.

## Antes de divulgar
- Troque o destaque editorial por um vídeo/post real selecionado pela equipe Buckets BR.
- Para cada publicação, inclua título, resumo, data e link original; os cards atuais são uma estrutura editorial inicial, não uma sincronização automática das redes.
- Confira os links sociais e de loja antes de publicar.

## Observações
Este é um protótipo estático. Não há painel administrativo, banco de dados, autenticação ou publicação automática de conteúdo. O quiz roda no navegador e não salva pontuações entre sessões.
